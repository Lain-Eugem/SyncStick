SyncStick 1.0.4 · U 盘自动同步
================================

一、运行
--------
双击本文件夹里的 SyncStick.exe。
不要只单独复制 exe 文件，旁边的 dll 和 json 文件需要和它放在一起。

运行环境：Windows 10 / 11 x64，且安装 .NET 10 Desktop Runtime (x64)。
这台电脑已经安装；如果复制到其他电脑，运行时下载地址：
https://dotnet.microsoft.com/download/dotnet/10.0

如果 Windows SmartScreen 弹出提示，点“更多信息” → “仍要运行”。
本程序没有代码签名，这只是 Windows 对未知发布者的常规提示。

二、第一次使用
--------------
1. 打开“同步内容”，添加要跟随的文件夹或文件。
2. 插入 U 盘，打开“目标设备”，点“设为目标”。
   USB 移动硬盘如果没出现，打开底部的“显示其他驱动器”。
3. 回到“同步总览”。“自动同步”开启时，之后每次插入这块 U 盘
   都会自动比较并写入有变化的文件。

三、关于覆盖和写入位置
--------------------
默认是“智能覆盖”：只写新增或变化过的文件，并覆盖 U 盘上的同名旧文件。
不会删除没选中的目录，除非在“设置”中主动开启“镜像清理”。

每个同步项都可以单独设置“U 盘内位置”：
- 留空：文件夹以自己的名字放进 U 盘根目录；文件直接放进根目录。
- 填相对路径：例如“我的项目\资料”，内容会写进 U 盘根目录下的这个文件夹。
- 点右侧的文件夹按钮：目标 U 盘已连接时，可以直接在 U 盘上选文件夹。
  还没有文件夹的话，可以在选择窗口里新建一个。
打开镜像清理前，请确认每个同步项的“U 盘内位置”。

四、退出与开机启动
------------------
关闭窗口默认最小化到任务栏右下角托盘，程序继续监听。
右键托盘图标可以打开、立即同步或退出。

Windows 11 可能会把新图标收进右下角的 ^ 里；点一下 ^ 就能看到，
也可以把 SyncStick 图标拖到任务栏上固定。如果开机后仍看不到图标，
再双击一次 SyncStick.exe 唤回主窗口。

如需开机自动启动：先把整个 SyncStick 文件夹放到固定位置，
再在“设置”中打开“开机自动启动”。移动文件夹后重新开关一次。

开机启动会优先写入当前用户启动项；如果被拦截，会改用启动文件夹
里的快捷方式。两种方式都失败时，程序会提示：从资源管理器重新打开
SyncStick.exe，再回到设置重试。由沙箱或受限权限启动的程序，
Windows 会拒绝写入启动项。

五、界面语言
------------
SyncStick 支持简体中文和 English。
打开“设置”，在“界面语言 / LANGUAGE”中选择“跟随系统 / 中文 / English”，
然后重启 SyncStick 生效。默认跟随系统；中文系统显示中文，其他系统显示 English。
也可以在命令行用 --lang zh 或 --lang en 临时指定本次运行的语言。
切换语言不会修改同步规则、路径或历史记录。

六、数据位置
------------
%APPDATA%\SyncStick\settings.json   配置
%APPDATA%\SyncStick\activity.json   最近 60 次同步记录
%APPDATA%\SyncStick\logs\           错误日志

SyncStick 不联网、不上传文件，也不需要管理员权限。
